# 財務規劃帳戶是虛擬信封，不是帳戶

雖然名稱沿用 Excel 的「財務規劃帳戶」，它在模型中不是 Account：它不持有錢，只記錄某部分資金的指定用途，每次入新資金、出資金、資金回流都同時作用在一個真實帳戶上。這樣資產負債表只加總真實帳戶，財務規劃帳戶永遠不會和銀行存款重複計算，Excel 中「勾選要算進資產負債表的財務規劃帳戶」的設定因此刪除。

## Consequences

- Excel 的「非手上現金」workaround（錢離開帳戶後只存在於信封裡，例如外幣現鈔）改為建立真實的現金類帳戶，並以「計入可用現金」屬性控制是否算進可用現金。
- 財務規劃帳戶不綁定特定帳戶，任一帳戶都可以進出任一財務規劃帳戶。
