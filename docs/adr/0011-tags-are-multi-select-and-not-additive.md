# 標籤可複選，標籤統計各自加總、不與總收支對帳

一筆交易最多可以掛 4 個標籤，所有交易類型都可以掛。標籤和分類互相獨立：分類回答「錢花在哪一類」，一筆交易只屬於一個分類；標籤回答「這筆屬於哪些事情」，可以同時是「日本旅遊」又是「可報帳」。標籤統計是每個標籤在某個歸屬月份的收入合計、支出合計與筆數，收支口徑沿用月報表（ADR 0008）：支出類交易依金額計入（包含電子錢包消費），貸款繳款以總額計入，轉帳、提款、加值、繳卡費、新增貸款與財務規劃三種只計筆數，不計金額。因為可以複選，同一筆交易會出現在好幾個標籤裡，**各標籤加總刻意不等於總收支**，也不列「無標籤」一列。

## Considered Options

- **一筆交易只能掛一個標籤**：各標籤加總加上「無標籤」剛好等於全部，可以畫成比例圓餅圖；但這樣標籤就只是沒有兩層結構的第三種分類，「日本旅遊」和「可報帳」不能同時掛在同一筆機票上，失去和分類分開的理由。
- **只有收入、支出可以掛標籤（比照分類）**：統計比較單純，但一趟旅行的換匯提款、悠遊卡加值、從旅遊基金出資金都串不進來，只能靠備註找。
- **統計依交易類型逐類加總**：轉帳、加值等類型的金額不是花費，和支出放在一起看會重複計算（例如提款 20,000 再支出 20,000），數字沒有意義。
- **標籤屬於個別成員而非帳本**：同一個月的標籤統計會因登入的人不同而不同，備份、還原與稽核都要多一個「誰的標籤」維度；目前帳本成員只有擁有者，這個複雜度沒有對應的需求。

## Consequences

- 日後若有人發現「各標籤加總 ≠ 月報表支出合計」，那是預期行為，不是 bug，不要改成單選或攤分金額。
- 標籤統計不能做成比例圖（圓餅、百分比堆疊），只能並列各標籤各自的合計。
- 非收支類型照樣可以掛標籤與依標籤篩選，只是不進金額；統計的筆數包含它們，讓使用者知道有幾筆交易沒有算進金額。
- 標籤是帳本設定項目，沿用設定項目的規則：被交易（含已軟刪除的）參照過就只能封存、不能刪除；改名、改色回溯套用到所有歷史交易與報表。
