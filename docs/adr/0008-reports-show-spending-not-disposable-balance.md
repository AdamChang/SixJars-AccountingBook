# 報表回答「錢花到哪裡」，不與月可用餘額對帳

月報表與年報表依分類歸組實際花費：電子錢包消費依分類計入、電子錢包加值不計入；貸款繳款以總額依貸款帳戶列示，並拆成本金與利息；預算的實際支出同樣包含電子錢包消費。月可用餘額則是現金流：扣加值、不扣電子錢包消費。兩者對同一批交易採用不同規則，所以報表的分類合計**刻意不等於**月可用餘額。月報表在最上方另列 `/summary` 的月可用餘額並說明差異來源（加值與消費的時間差、未付的預定支出），而不是把其中一方的規則改成和另一方一致。

## Considered Options

- **報表沿用月可用餘額的規則（計入加值、排除電子錢包消費）**：數字能對上，但用悠遊卡付的午餐不會出現在「主食」，加值會變成一筆沒有分類的支出，報表無法回答「花到哪裡」。預算也會因此看起來比實際寬鬆。
- **月可用餘額改成計入電子錢包消費**：等於在加值時與消費時重複扣款，或必須改成加值不扣款，與 Excel 原本的現金流定義及 P1 的驗收比對全部衝突。

## Consequences

- 日後若有人發現「報表支出合計 ≠ 月可用餘額」，那是預期行為，不是 bug，不要「統一」兩邊的規則。
- 驗收比對 Excel 時，報表數字對照月工作表的分類小計，月可用餘額仍對照原本的 `J6`；兩組比對各自成立。
